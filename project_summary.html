Problem Statement

Regional sales managers at a mid-size retail company were spending significant time each week manually compiling sales and profit reports across four geographies — North, South, East, and West. Performance comparisons required pulling data from multiple spreadsheets, leading to version inconsistencies, delayed decisions, and missed opportunities to act on margin erosion signals early.

Stakeholders needed a single consolidated view that could answer questions like: Which region is trending down this quarter? Which product categories are hurting margins? What will next quarter's revenue look like? — without analyst intervention for every query.

Approach
1
Data Preparation: Connected Tableau to a structured CSV dataset (600 orders, 14 columns) covering Order Date, Region, Category, Sub-Category, Product, Sales, Profit, Quantity, and Discount from 2021–2023.
2
Calculated Fields: Authored 13 calculated fields covering profit ratios, running totals, YoY growth, regional ranks, dynamic KPI switching, and date granularity controls — enabling rich analysis without data transformations.
3
Dynamic Parameters: Implemented 5 parameters (KPI Selector, Top N Products, Date Granularity, Profit Threshold, Discount Threshold) giving business users on-the-fly control over every chart axis and filter — no analyst intervention required.
4
Visualization Design: Built 6 chart sheets including a dual-axis time series, treemap, heatmap, forecast line chart, and two dynamic bar charts — each using a consistent color vocabulary and cross-sheet filter actions.
5
Dashboard Assembly: Composed all 6 sheets into a single 1400×900 dashboard with global filters, drill-down actions, parameter control strips, and a clean layout optimized for executive presentation.
Charts Built
1 Regional Sales Comparison Bar Chart

Horizontal stacked bar chart breaking total revenue by Region and Customer Segment. Includes average reference line and dynamic KPI axis via the KPI Selector parameter.

2 Sales vs. Profit Trend Dual-Axis

Dual-axis chart overlaying Sales bars and Profit trend line over time. Date granularity (month/quarter/year) controlled by parameter. Divergence signals margin compression.

3 Category Performance Treemap

Treemap with rectangle size = Sales, color = Profit (diverging red-green palette). Sub-Category labels enable instant identification of high-volume/low-margin combinations.

4 Profit Ratio by Region Heatmap

4×4 highlight table (Region × Category). Color encodes profit margin with a dynamic threshold reference driven by the Profit Ratio Threshold parameter slider.

5 Top N Products Dynamic Bar

Parameter-driven ranked bar chart showing the top 3–25 products by Sales. Updates instantly as users drag the Top N slider — no filter editing needed.

6 Sales Forecast Line + Forecast

Four-region trend lines with Tableau's built-in exponential smoothing forecast (95% CI). Trend lines show growth trajectory. Running total overlay available as second axis.

Key Technical Features
Dynamic KPI Switching

A string parameter + calculated field swaps the chart metric (Sales / Profit / Quantity) across all sheets simultaneously without duplicating views.

Table Calculations

Running totals, YoY growth (LOOKUP), window averages, and regional rank (RANK) enrich standard aggregations with analytical depth.

Cross-Sheet Filter Actions

Clicking a region bar instantly filters all 6 sheets. Hovering over a category highlights matching marks across the entire dashboard.

Forecast & Trend Lines

Tableau's native forecasting (exponential smoothing) projects 3-month forward revenue per region, with 95% prediction intervals displayed.

Dual-Axis Visualization

Synchronized secondary axis overlays Sales (bars) and Profit (lines) on a single chart, enabling immediate correlation and divergence analysis.

Date Granularity Control

DATETRUNC-based calculated field tied to a parameter lets users switch between monthly, quarterly, and yearly views on all time-series charts.
